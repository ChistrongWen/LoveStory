# 爱情岛

Independent static ES-module integration of https://github.com/Humpalumps/Ultra-Water (upstream tree 30ea65ecb0a66b137aa200d099965634bdd84d51).

The original ocean/island rendering is preserved. The page adds a Chinese title, caption, back link, loading/error message, and initially collapses the settings. Runtime dependencies are pinned in the import map (three 0.186.1; lil-gui 0.21.0), served by jsDelivr. Serve this folder over HTTP(S); no build step is required. LICENSE and THIRD_PARTY_NOTICES.md retain upstream attribution.
