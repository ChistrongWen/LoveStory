# 与你岁岁年年 · 两人的共同手账

静态网页部署在 GitHub Pages，私有数据和文件由 Supabase 保存。前端配置只有公开密钥，访问由登录身份、`love_members` 和数据库行级权限控制。

## 共同维护

两位成员使用各自的手账账号登录后，可共同使用：

- 回忆与多图相册：添加、查看、删除；可编辑标题、日期、主题、地点和正文，编辑文字时保留照片。
- 待办：新增、修改文字、勾选和删除。
- 纪念日：2023.08.22 公开显示，访客可查看相伴天数；执行 `public-anniversary.sql` 后，成员修改的日期也会同步公开。该函数只返回纪念日，不开放其他设置。
- 世界地图：新增、编辑、删除地点及链接；首页展示共同地点。
- 便签：点击“编辑共同便签”，每行一条。
- 背景音乐：登录后选择音频即可上传共享，支持 MP3、M4A、WAV、OGG、WebM，最大 20 MB。

页面可见时每 2 分钟自动刷新，也可手动刷新。地图、便签、纪念日和回忆文字有版本检查，发生并发修改时提示重新编辑。退出后回到本机内容，纪念日始终显示公开日期。

## 本机及旧云端迁移

- 本机回忆：登录后点击“迁移本机回忆”。
- 本机待办：点击“共享本机待办”，重复操作不重复添加。
- 本机纪念日：点击“共享本机纪念日”。
- 本机地图：进入世界地图，点击“共享本机地点”。
- 旧云端：页脚“导出旧云端回忆”打开 `legacy.html`，使用原账号导出；回到新手账，切到本机导入，再登录新云端迁移。旧云端不会被自动清空。
- 原音乐文件：在新云端登录后重新选择音频文件即可共享。

“导出手帐备份”包含当前模式的回忆、照片、待办和纪念日。地图提供独立导出。请保留原始音乐文件；便签和音乐目前不包含在回忆备份中。

## 新项目初始化

依次执行 `supabase-setup.sql`、`supabase-todos.sql`、`cloud-settings.sql`。最后一个为一次性扩展脚本；不要重复运行初始化。通过 Supabase Authentication 创建成员账号，然后由管理员将其 UID 加入同一本手账的 `love_members`。

将 Project URL、publishable key、journal UUID 填入 `supabase-config.js`。不要把数据库密码、用户密码或管理密钥写进仓库。`legacy-supabase-config.js` 专供旧云端迁移入口。

## 验证

运行 `node --test test-*.cjs`。测试覆盖本机兼容、云端相册、共同待办、纪念日/便签/音乐同步、地图同步和并发编辑保护。真实项目还应验证两个成员的互相读写和非成员拒绝访问。

## 公开纪念日配置

在新项目 SQL Editor 执行 `public-anniversary.sql`，将日期设为 2023-08-22，并提供仅返回此手账纪念日的只读函数。未配置时首页仍显示确认过的日期，云端日期编辑暂不可用，避免访客和成员看到不同日期。此脚本再次执行会将日期重设为 2023-08-22。不授予匿名用户访问数据表或写入的权限。
